Give the kernel a way back

A Kaggle kernel accepts no incoming connections, so it dials out to a Cloudflare tunnel and this panel talks to that hostname. Your server never needs an open port.

Where to get the token
one.dash.cloudflare.com → Networks → Tunnels → Create a tunnel
Route a public hostname to http://localhost:8188, then copy the token.
